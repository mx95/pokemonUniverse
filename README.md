# Pokémon Genesis

Original GBA Pokémon RPG set in the **Aurelia** region, built on [pokeemerald-expansion](https://github.com/rh-hideout/pokeemerald-expansion) `1.17.0`.

See [docs/GENESIS.md](docs/GENESIS.md) for project setup, branch map, and development rules.

## Quick build

```bash
make -j$(nproc)
```

Produces `pokemonGenesis.gba`.
